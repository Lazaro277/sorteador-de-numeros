# Sorteador de Números

Aplicação web para realizar sorteios de números dentro de um intervalo definido pelo usuário, com opção de permitir ou impedir repetições.

**[Acessar aplicação](https://lazarom.dev/sorteador-de-numeros/)**

## Funcionalidades

- Definir o intervalo mínimo e máximo do sorteio.
- Escolher a quantidade de números que serão sorteados.
- Realizar sorteios com ou sem repetição.
- Validar os valores informados pelo usuário.
- Exibir os números sorteados individualmente.
- Apresentar animações durante a exibição dos resultados.
- Realizar novos sorteios sem precisar recarregar a página.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Conceitos aplicados

- Manipulação do DOM.
- Eventos e interação com formulários.
- Validação de entradas.
- Funções e estruturas de repetição.
- Geração de números aleatórios.
- Arrays e estruturas de dados.
- Algoritmo de sorteio sem repetição.
- Manipulação de classes CSS.
- Animações e controle de execução assíncrona com Promises e `async/await`.

## Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/Lazaro277/sorteador-de-numeros.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd sorteador-de-numeros
   ```

3. Abra o arquivo `index.html` no navegador.
